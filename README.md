# 森友消消

原创中文森林三消小游戏。双击 `开始游戏.cmd`，或在浏览器打开 `dist/index.html` 即可游玩，无需安装。

- 8×8 棋盘，6 种原创 SVG 动物，12 个逐步解锁的关卡。
- 交换相邻动物，横竖至少三个同色即可消除。无效交换不扣步数。
- 四连生成行列特效，T/L 形生成 3×3 爆炸，五连生成彩虹花；特效可组合。
- 第 4 关开始有固定在格子上的冰块，消除覆盖其上的动物即可破冰。
- 提示不限次数，每关各有 2 次洗牌、2 次小锤，道具不扣步数，无解自动免费洗牌。
- 支持鼠标点击、触屏滑动和键盘；Shift + 方向键交换。
- 音效默认关闭，可点右上角音符开启。关卡、星级和最佳分数保存在当前浏览器；未完成的对局不保存。
- 三星规则：过关得一星，剩余至少 5 步得二星，至少 11 步得三星。

开发：`node server.cjs` 后访问 `http://127.0.0.1:4173`。验证核心规则：`node --test engine.test.cjs`。

本项目借鉴通用三消规则，界面、角色与关卡独立制作。未使用开心消消乐的名称、角色或素材。
